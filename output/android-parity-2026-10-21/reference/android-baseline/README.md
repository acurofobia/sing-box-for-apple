# WhiteLink для Android

Тестовый Android-клиент локального iOS prototype: один системный VPN/TUN, один Go runtime sing-box, ручной выбор VLESS или VK TURN, те же локальные правила белых списков.

## Установка и проверка

1. Установите `dist/WhiteLink-0.1.0-test.apk` на Android 7.0 или новее. Включите разрешение установки из выбранного источника. Сборка включает ARM64 для телефона и x86_64 для эмулятора; 32-битные телефоны не поддерживаются.
2. Откройте «Настройки», вставьте ссылку подписки и нажмите «Загрузить / обновить». Можно отдельно вставить VLESS JSON, открыть JSON-файл или вставить `wdtt://` / `vkturnproxy://import?data=…`.
3. Выберите VLESS или VK TURN на экране подключения, нажмите «Подключить» и разрешите Android VPN. Фоновое уведомление содержит кнопку отключения.
4. Проверьте сайты, видео, UDP и DNS. При ошибке сохраните журнал и CSV во вкладке «Журнал».
5. Проверьте переключение Wi-Fi ↔ мобильная сеть, смену режима во время соединения и отмену во время получения TURN-доступа.

Конфигурации сервера не включены в APK. TURN в этой версии использует WRAP-A + DTLS + GETCONF с паролем; legacy SRTP-ссылки отклоняются при импорте. Android создаёт отдельный ID установки: пароль TURN, привязанный сервером к iPhone, может не подходить этому устройству. Переустановка меняет ID.

«Прямой режим» — отдельная диагностика, в которой трафик идёт напрямую. Он включается вручную. Без системного Android lockdown отключение/перезапуск VPN возвращает обычную сеть.

Debug-сборка допускает HTTP-подписку только по localhost или IP локальной сети. HTTPS нужен для публичной подписки. Redirect отклоняется; `sing_box_url` должен иметь тот же origin, что подписка.

## Архитектура

`MainActivity` → `VpnController` → `WhiteLinkVpnService` → libbox `CommandServer` → TUN/gVisor → общий route → VLESS или native WireGuard с detour `vk-turn-transport` → TURN/WRAP-A/DTLS.

Приложение формирует DNS, TUN, маршруты и файловые пути. Из импортированного sing-box JSON извлекается только VLESS outbound. Все 21 `.srs` включены в assets; порядок direct/reject/proxy правил сохранён. Неописанный трафик тоже идёт в proxy. IPv6 захватывается системным VPN и блокируется: полноценный IPv6 через proxy в этой версии отсутствует.

Внешние sockets защищаются `VpnService.protect(fd)` и привязываются к физической `Network`. TURN bootstrap DNS использует эту сеть. Смена сети отменяет старое поколение и восстанавливает тот же режим. Одновременно не запускаются два core. Снимок настроек хранится в AES-GCM с Android Keystore, атомарно, в каталоге без backup.

UI и core находятся в одном процессе: RSS/PSS включают интерфейс. Счётчик WG transport измеряет зашифрованные WireGuard datagrams на границе транспорта, без наружного overhead RTP/DTLS/STUN. Он не равен пользовательскому трафику. Число TURN-сессий показывает установленные соединения после handshake; transient allocations во время bootstrap отдельно не считаются. CSV ограничен размером и ротацией; журнал ограничен 1000 строками в памяти и 512 КиБ на диске.

## Сборка

Нужны Windows PowerShell, Go 1.26.4, JDK 17+, Android SDK Platform 36, Build Tools 36.0.0, NDK 30.0.14904198 и интернет для зависимостей. Сборка проверена с JDK21. Скрипт ядра устанавливает зафиксированные gomobile/gobind; Gradle Wrapper использует Gradle 9.1.0. Для пути с кириллицей скрипт временно создаёт свободную ASCII-букву диска к той же папке и удаляет её после сборки.

```powershell
.\scripts\build-apk.ps1 -Sdk 'C:\Android\Sdk' -Java 'C:\Program Files\Android\Android Studio\jbr'
```

Если AAR уже собран, добавьте `-SkipCore`. Скрипт выполняет сборку APK, unit tests и Android lint. Исходники и точные зависимости находятся рядом с APK; сведения о версиях и хешах — в `dist/build-manifest.json`.

## Происхождение

- SFA: `bc73504fcb858400a939140ad785ed92f4c9f429`, исходник VPN/platform integration.
- sing-box: `af6e64c3b69e6132ebaee0e1a3d24e93903f6709`, полный локальный `sing-box-vk-turn-prototype.patch` и Android-адаптация.
- TURN: локальный `sing-prototype/ThirdParty/VKTurnProxy`, vendored без собственного WireGuardBridge/TUN в сетевом тракте.

Android-оболочка компактная, с новым package ID и именем. Из SFA перенесена платформенная интеграция, а не весь редактор профилей, Room, shell и дополнительные сервисы. Поэтому набор Gradle/UI зависимостей меньше исследованного SFA, а SDK выбран из установленного совместимого набора. Одно сетевое ядро и формат двух режимов сохранены.

Ограничения этой тестовой версии и фактически выполненные проверки перечислены в `dist/TESTING.md`. Совместимость с вашим шлюзом и длительная работа на телефоне требуют проверки пользователя.
