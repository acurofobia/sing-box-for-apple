# Sing Android — комплект для разработки с Codex

Снимок интерфейса и исходников от **20 октября 2026**, часовой пояс Asia/Yekaterinburg.

1. Скопируйте каталог `design-handoff/` в обычную папку на Windows.
2. Откройте **START_HERE.html** двойным щелчком: это локальная галерея, интернет не нужен.
3. Откройте эту папку в Codex или скопируйте её в Android-репозиторий как `design-handoff/`.
4. Передайте Codex текст из **CODEX_START_PROMPT.txt**. Если комплект вложен в Android-проект,
   добавьте в его корневой AGENTS.md ссылку на `design-handoff/AGENTS.md`: вложенные инструкции
   сами по себе не управляют кодом за пределами своей папки.
5. Начните с подключения, затем реализуйте профиль, режимы и роутинг. Проверяйте каждый экран
   скриншотом Android-эмулятора.

Внутри: 11 макетов в PNG 1x и 2x, точные JSON-координаты видимых слоёв
с раскрытыми символами, стили, ресурсы, скриншоты iOS-приложения, документация поведения,
примеры данных, локальный тестовый сервер и части Swift-кода для сверки логики.

Приоритеты: текущие Swift-исходники определяют поведение; снимки приложения показывают реальный
результат; PNG/JSON макетов задают визуальную геометрию. Системные панели Android адаптируются
по docs/ANDROID.md. Значения баланса, ID, пинга, времени и трафика в эталонах — примеры данных.

Все 11 экранов перечислены в design/spec/screens.json. Исходник Sketch хранится локально
и не входит в публикуемый комплект. Архивный экран «Где взять ссылку?» не входит
в реализуемую матрицу.

Комплект не является Android-проектом, APK, VPN-ядром или полной сборкой iOS. Swift-срез включает
импорты из исходного проекта; использовать его нужно для чтения и переноса логики. Для полного
сетевого порта потребуются отдельная интеграция ядра, жизненный цикл VPN и Android-проверки.

Проверка целостности: `python tools/verify_package.py` (Windows: `py -3 tools/verify_package.py`).
Python не нужен для просмотра изображений, HTML и видео. Подробнее — docs/CONTENTS.md.
