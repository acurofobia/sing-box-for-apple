# Что находится в комплекте

| Путь | Назначение |
|---|---|
| START_HERE.html | Локальная галерея: макет, скриншот приложения, координаты, PNG 2x |
| design/screens/1x/ | 11 экранов 390×844 пикселей |
| design/screens/2x/ | 11 экранов 780×1688 пикселей |
| design/CONTACT_SHEET.png | Обзор всех экранов |
| design/spec/screens.json | Соответствие имён файлов, экранов и ID Sketch |
| design/spec/tokens.json | Цвета, размеры, типографика, радиусы, параметры жестов |
| design/spec/layouts/ | Видимые слои с координатами относительно экрана и раскрытыми символами |
| design/spec/strings-ru.json | Русские подписи из макетов, включая примерные динамические значения |
| design/assets/ | Исходные PNG ресурсов и SVG индикаторов выбора |
| reference/app-screens/ | 11 скриншотов настоящего приложения, приведённых к 390×844 |
| reference/videos/ | Короткий дополнительный видеоэталон жеста VPN-карточки |
| reference/ios-source/ | Swift UI/модель/контракты, роутинг, списки правил, UI-тесты, LICENSE |
| fixtures/ | Искусственные ответы сервера, JSON Schema и локальный HTTP-сервер |
| docs/ | Поведение, Android-адаптация, контракты, проверка и происхождение |
| tools/verify_package.py | Проверка SHA-256 каждого файла и структуры комплекта |
| MANIFEST.json | Размеры и SHA-256 файлов |

JSON layouts содержит `frame` относительно родителя и `screenFrame` относительно верхнего левого
угла экрана. `path` различает повторяющиеся ID во вложенных экземплярах символов. Скрытые слои
не включены. Эффекты масок, наложения и Apple-компоненты точнее представлены PNG и исходником
Sketch, который хранится локально и не публикуется: JSON является спецификацией,
а не универсальным движком отрисовки Sketch.
Числовой fontWeight в layouts использует шкалу Sketch 0…12, а не CSS/Android weight;
для семантических начертаний сверяйтесь с typography в tokens.json и Swift-источником.

Растровые ресурсы из приложения сохраняют исходный размер. Суффикс @3x отражает масштаб iOS,
а не необходимость использовать те же физические пиксели на каждом Android-устройстве.
SVG-индикаторы не содержат встроенных растровых картинок и файлов шрифтов.
