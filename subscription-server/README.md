# Сервер единой подписки

Нужен Python 3. Сторонние пакеты не требуются.

```sh
cd subscription-server
cp .env.example .env
python3 -c 'import secrets; print(secrets.token_urlsafe(32))'
```

Вставьте сгенерированный токен в `SUBSCRIPTION_TOKEN` и сохраните в `config.json` только параметры VLESS: JSON-объект с одним VLESS outbound в `outbounds` или отдельный объект outbound. `route`, `dns`, `inbounds` и служебные настройки не нужны — их задаёт приложение prototype. `SING_BOX_CONFIG_PATH` задаётся относительно `.env` либо абсолютным путём. Файл должен содержать JSON-объект без комментариев.

При необходимости укажите `VK_TURN_LINK` (`wdtt://…` или `vkturnproxy://…`). Значения с пробелами и символом `#` заключайте в кавычки. Пустой `VK_TURN_LINK` отключает VK TURN; пустой `SING_BOX_CONFIG_PATH` отключает VLESS. Тариф и срок подписки больше не задаются.

```sh
python3 server.py
scutil --get LocalHostName
```

В iPhone в той же домашней сети введите `http://<LocalHostName>.local:8080/subscription/<SUBSCRIPTION_TOKEN>`. Разрешите приложению доступ к локальной сети. Если macOS Firewall блокирует соединение, разрешите входящие подключения Python в системных настройках. Проброс портов не нужен. HTTP-ссылка предназначена для доверенной домашней сети: токен и конфигурация передаются без TLS.

Ответ подписки содержит ровно два поля:

```json
{
  "sing_box_url": "http://mac.local:8080/subscription/<SUBSCRIPTION_TOKEN>/config",
  "vk_turn_link": "wdtt://…"
}
```

Для отключённого режима соответствующее поле равно `null`. Ссылка `sing_box_url` формируется из адреса, по которому приложение обращается к серверу. JSON остаётся на Mac и выдаётся отдельно по `/subscription/<SUBSCRIPTION_TOKEN>/config`, с тем же токеном. Прямой доступ к `/config.json` и `.env` закрыт. Прототип скачивает JSON по ссылке и импортирует из него VLESS; данные тарифа, срока, версии схемы и встроенный конфиг в ответ подписки не входят.

Сервер перечитывает `.env` при каждом запросе и JSON при обращении к ссылке конфигурации. После изменения `HOST`, `PORT` или кода сервера перезапустите его. При изменении токена потребуется заменить ссылку в приложении. Недоступная или некорректная конфигурация даёт HTTP 503 по ссылке конфига; неверный токен, отключённый конфиг и остальные пути — HTTP 404. При ошибке загрузки подписки или JSON прототип сохраняет предыдущие конфигурации.

Mac должен быть включён и сервер должен работать для обновления. Вне домашней сети iPhone использует сохранённую подписку. Если VPN исключает доступ к локальной сети, остановите его для обновления.

Проверки (из корня репозитория):

```sh
python3 -m unittest discover -s subscription-server/tests -v
```

В ветке prototype приложение импортирует только VLESS outbound (`R3-N1`, либо единственный VLESS outbound). `route`, `dns`, `inbounds` и остальные outbounds из файла игнорируются: маршруты, DNS и интерфейсы задаёт приложение. Поэтому для прототипа достаточно JSON с одним VLESS outbound в `outbounds` или отдельного объекта outbound, без роутингов. Исходный файл сервера автоматически не перезаписывается.

Этот формат предназначен для prototype. Основное приложение с прежним загрузчиком `ManagedSubscriptionService` требует старый формат и с этим ответом несовместимо.
