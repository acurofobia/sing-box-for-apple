## Сторонние сервисы

VK TURN использует API и relay стороннего сервиса. Нужно отдельно подтвердить допустимость используемого способа доступа и транспортного применения по условиям VK. Лицензия на код библиотеки не предоставляет прав на инфраструктуру сервиса. Собственный выходной сервер пользователя не исключает обращения к VK в этом режиме.

## Публикация и решения владельца

- Опубликовать privacy policy по постоянному HTTPS URL и указать его в App Store Connect. Локальный текст подготовлен с предоставленными разработчиком именем и контактом; инструкция — `docs/release/privacy-policy-publication.md`.
- Обеспечить получателям сборки доступ к соответствующему архиву исходников и дать ясную ссылку рядом с материалами выпуска. Локальный архив не считается опубликованным только потому, что он создан на Mac. Репозиторий разработки не обязательно соответствует установленной версии.
- Уточнить при необходимости применение Apple 5.4 к универсальному клиенту на индивидуальном аккаунте. Это риск трактовки App Review, а не установленный безусловный запрет для этого клиента. Описать модель self hosting в Review Notes без заявления, что отсутствие продаж автоматически создаёт исключение.
- Завершить export compliance для фактической криптографии и проверить территории распространения. Значение exemption не назначать без основания.
- Подготовить тестовую конфигурацию и инструкции для внешнего Beta App Review, distribution signing и профили. Публичная VPN-инфраструктура разработчика для этого сама по себе не требуется.

Источники: [TestFlight terms](https://www.apple.com/legal/internet-services/itunes/testflight/sren/terms.html), [Apple Guidelines](https://developer.apple.com/app-store/review/guidelines/), локальные grants и уведомления в комплекте лицензий. Отсутствие явной лицензии или сведений о происхождении отмечает незакрытый вопрос проверки; само по себе это не доказательство нарушения.
